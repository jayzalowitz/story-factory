# The Letter to the Father: source-project example

This is the feature project from which Story Factory's process was extracted. It was developed before the new command suite existed. These are real finished development documents, not evidence that the current commands automatically generated this feature or guarantee its quality.

[Read the screenplay](../../site/examples/the-letter-to-the-father/screenplay.pdf) · [Read the studio package](../../site/examples/the-letter-to-the-father/studio-package.pdf) · [Browse the public gallery](https://jayzalowitz.github.io/story-factory/#examples)

Measured public build: **106 screenplay pages, 45 package pages, and sixteen pitch PDFs, each exactly one page.** manifest.json records page counts and SHA-256 hashes. The screenplay includes title/divider material; PDF pages are not a measured running time.

Source snapshot: original the-letter-to-the-father project at b91ffbf. See [the development history](../../docs/ORIGIN.md): original creative doctrine, first build and frank critique, consequential structural rewrites, and 116 recorded refinement cycles. The surviving original directive and initial development notes are preserved in skills/story/references/. No original chat transcript or exact loop scheduler was recovered.

Publication changes are limited to date/draft/status labeling, portable root font paths, proposed rather than attached casting language in key pitch locations, and a shortened, qualified financier pitch. A notice on every PDF page identifies the development-only status. This is an adapted public example, not a byte-identical archival edition.

**All talent, financing, budgets, incentives, business comparisons, distribution, festival and awards language is illustrative historical development copy. No attachments, interest, financing, selection or outcome is confirmed.** It is not current investment information. Historical portrayal and reconstructed dialogue are not certified by a newly completed source audit. The new research and truth-review system should be used before making factual promises in a new project.

The source assembly is editable. From this directory run `make all` with the repository's fonts and the print tools described in docs/SETUP.md. PDFs build into ignored output/. Public copies live under site/examples/ so Pages publishes only reviewed website files. This example is useful for tone, sustained scene writing, synchronized materials, and formatting; its specific Kafka/Brody creative choices are not defaults for new films.

Known inherited layout limitation: physical screenplay page 2 contains only “FADE IN” before the first movement divider. The historical feature pagination is retained rather than presenting it as a flawless new typesetting pass. Sample review inspected cover/interior/end pages and every pitch, not a fresh full-page visual audit of all 151 core pages.
