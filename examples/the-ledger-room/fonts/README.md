# Vendored Fonts

This directory contains repo-local, open-source metric-compatible replacements
for the project's previous system-font fallback path.

- `Tinos-*` replaces the Times New Roman fallback.
- `Arimo-*` replaces the Helvetica fallback.
- `Cousine-*` replaces the Courier New fallback.

Sources:

- `Tinos-*` from `google/fonts` at `apache/tinos`
- `Cousine-*` from `google/fonts` at `apache/cousine`
- `Arimo-*` from `googlefonts/Arimo` at `fonts/ttf`
