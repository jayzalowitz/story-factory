## Bugs found and repaired during the audit

1. **Stale truth approval:** changing source mode, departures, local source evidence, research notes or audience wording could previously leave a receipt current. Reviews now bind those inputs and reject missing legacy bindings; changing/removing the source mode cannot silently bypass an existing truth review. Five meaningful regressions added across the truth/team changes.
2. **Research-worker path contradiction:** research guidance assigned workers outside the validator's allowed folder. It now consistently uses disjoint development/workers/research-* paths; strict validation is retained.
3. **Stale example handoff:** a reader-link edit changed the feature README after its handoff. The actual current copy was reviewed and handoff revalidated, with manuscript/PDF hashes unchanged and the curation manifest refreshed.

## Limits that remain explicit

AI simulations are not a human study. Native trials do not validate every command, GUI signup, every operating system or universal artistic equivalence. Native Claude resume returned but its status/fixture summary had fidelity errors; native memory writes were blocked or contested. The optional adapter stays deferred. The shared local memory service experiment is narrow single-owner evidence, not an operated multi-user production service. Human performance/runtime, commercial demand, line budgeting, legal clearance and the historical feature's real-world factual claims are not certified.

These limits do not hide an unfinished default dependency: the main workflow uses ordinary project files and one assistant. No additional account, memory service or parallel team is required to write.
