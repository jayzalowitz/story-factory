The coordinator recorded an auto-mode plan before launching, observed native availability in the current team context, capped the assignment at one worker/one round/no external research, and ran authorize_plan. The returned native launch handle and activity were then checked against the exact plan. Both preflight and activity validation passed.

Usage was unavailable and remains unknown. This is a narrow actual native-host assignment test, not proof that arbitrary hosts enforce these limits or that the helper validates its own reports. The Python checker validates records, not native tool interception or dollar spend.
