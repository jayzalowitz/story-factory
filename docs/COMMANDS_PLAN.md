# Installable story commands

Build one source suite of Agent Skills, installable into Claude Code (.claude/skills) and Codex (.agents/skills). Keep common craft references and a portable exporter/toolkit with the router skill. Stage skills load only the relevant common reference and their own procedure. No dependency on an existing checkout after installation, no model API client, no paid services, no generic gstack code copied.

Commands (18, see COMMANDS.json): story, story-new, story-office-hours, story-research, story-premise, story-outline, story-draft, story-review, story-studio, story-revise, story-bechdel, story-quality, story-truth, story-package, story-check, story-handoff, story-resume, story-run. Claude uses /story-…; Codex uses $story-… or its skill picker. The command is interpreted by the user's coding assistant. A shell workflow command only tracks artifacts and never claims to generate or judge art.

Include the full surviving original creative brief and original development critique, clearly historical and optional. Keep generalized master guidance and staged workflow authoritative for new stories. Bundle examples illustrating choices, structural review, bad/good scenes, Bechdel assessment, a quality rubric, and a complete small demo. Do not pretend to recover missing transcripts or certify quality by file count.

Implementation: portable installer with host/project options, idempotent reinstallation, refuse conflicting/unowned skills, project-only by default; no home/config changes unless user chooses a target. Exporter includes both hosts' skills in new projects. Install snapshots copy only known source directories and exclude generated installations/context/history. A status command prints a command recommendation. Stage completion reports explicit evidence and invalidates on upstream changes; quality and Bechdel reports are required for revised-draft completion. Build command requires real PDF evidence, never placeholder output as completion.

Validation: host layouts, no-conflict and no-partial-install behavior, source deletion portability, Unicode/space paths, embedded exporter operation, exported commands, reference discovery, stale receipts and quality reports, skill validators, native suite, PDF smoke, and independent realistic skill forward-test on this host. Review public Git history/assets for secrets and personal paths before changing repository visibility. User explicitly authorized making the whole toolkit public and publishing the existing site; no paid host or custom domain. Original public destination remains jayzalowitz.github.io/story-factory/ once visibility permits Pages.
