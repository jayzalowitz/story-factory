# Preview build: completed work and remaining limits

Version 0.2.0-preview.1 is a working preview, with the same guided quality process for beginners and experienced writers. It does not guarantee artistic success.

| Approved work | Delivered | Remaining limit |
|---|---|---|
| 1. Beginner setup and complete journeys | Read-only setup check, chosen-assistant instructions, three explicitly AI-simulated beginner journeys, actual native Codex short | No human study or fresh GUI signup test. Claude built and repaired a short but timed out before a clean final return. |
| 2. Bring existing writing | Preserved originals and location records for Fountain, FDX, text, Markdown, DOCX and text PDF; approval before rewriting | Scans require OCR or a text copy; extraction is not a complete reading. |
| 3. New feature and substantive revision | The Ledger Room: full independent AI reading, documented findings, targeted revision, screenplay and optional studio materials | AI judgment and visual review do not replace performance testing or professional clearance. See the example's scoped evidence. |
| 4. Researched true-story examples | Twelve Seconds demonstrates based-on research and adaptation; The Pool demonstrates an inspired-by promise and its limits | Sources are institutional retrospective accounts, not independently corroborated primary evidence. |
| 5. Optional parallel helpers | Off/ask/auto controls, exact-plan approval, bounded native worker trial and activity receipts | Workflow checks cannot intercept every native tool or enforce a provider dollar budget. Defaults stay off. |
| 6. Optional memory experiment | Actual isolated GBrain save, recall, correction, withdrawal, routing and concurrent-read pilot | Native activation, shared writes and recovery unverified; adapter deferred. Ordinary project files remain authoritative. |
| 7. Selected delivery and examples | Current-build/quality/source checks, every-page visual receipts, selected PDF/editable manifests, short and feature galleries, corrected historical opening layout | Delivery prepares local files; it never sends them. The historical 105-page edition has a scoped opening-layout inspection. |
| 8. Versioned distribution | Versioned source ZIP, hashes, owned-helper upgrades, compatibility table and public release workflow | Preview compatibility is limited to the observed environments listed in COMPATIBILITY.md. |

Start with [the beginner guide](START_HERE.md). Evidence: [validation](VALIDATION.md), [compatibility](COMPATIBILITY.md), [simulations](SIMULATED_USABILITY.md), [team trial](TEAM_TRIAL.md), and [memory pilot](GBRAIN_PILOT.md).
