Read the current draft/quality/research reports and the source files. Run `python3 scripts/story_check.py source`, `quality`, and `truth`; any failure needs investigation rather than a waiver invented by the agent. Run `python3 scripts/story_check.py build`. It checks placeholders, forces the actual Makefile build, measures selected PDF outputs with pdfinfo, checks every selected pitch fits one page (18 outputs/16 pitches when all selected), and records source/output hashes. If print tools are missing, report what is missing and offer setup; do not say the build passed. Ordinary prose drafting can continue without PDF tools.

Render and inspect samples of screenplay dialogue, scene/page boundaries, package contents and EVERY pitch; repair clipping and overflow while preserving readable type. Record tools, commands, actual page counts and any title/divider pages, visual observations, continuity/factual checks, and limits in development/verification.md. Re-run changed inputs. Use `Verdict: PASS` only with actual source, quality, truth, PDF, and visual evidence. The build receipt cannot certify artistic or legal quality. Complete verify only after these checks pass; never count a placeholder scaffold PDF as a completed screenplay.

Read DELIVERY.md. The assistant owns the default quality checks and repair work; do not reduce rigor because the writer is a beginner.
