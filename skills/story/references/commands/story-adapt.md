# story-adapt — Turn source material into a movie

Claude Code: `/story-adapt`. Codex: `$story-adapt` or the skill picker.

> /story-adapt Adapt my novel into a feature. Read it first, help me choose what the film keeps, and make the finished screenplay and producer pitch.

> $story-adapt Turn these interview transcripts into a short. Preserve the speakers' meaning, show me the proposed changes, and explain what needs permission.

Read COMMON.md, ADAPTATION.md, QUALITY.md, the actual source files, brief and existing status. If factual, also read RESEARCH.md. Follow TEAMS.md only when the writer enabled helper teams; otherwise work sequentially.

1. Preserve and inventory the material; identify source kind, version, whole-source reading scope, extraction gaps and source-use basis. Ask for missing material rather than pretend a summary is a full read.
2. Read the agreed complete source and propose a filmable story, viewpoint, length, preserved essentials and possible changes. Use the host's question interface to approve the fidelity contract and consequential departures.
3. Create adaptation/project.json and a source-to-beat outline. Keep adaptation selection distinct from factual source mode. For real people/events, run the research/truth path as well.
4. Draft the complete agreed screenplay with stable scene IDs. Track source locations, omissions, compression, composites and invented dialogue. Apply only approved consequential departures; preserve the original source files.
5. Do the full editorial read and substantive revision automatically. Perform current-draft fidelity and applicable truth/craft/agency/Bechdel reviews. A narrow representation test is not a screenplay-quality score.
6. Write evidence-based adaptation/review.md and review.json; run scripts/adaptation.py current. Continue through selected package creation, actual PDF build, page inspection and handoff. Report actual deliverables and open limitations without promising identical artistic outcomes.

If the writer supplies only an excerpt, deliver an excerpt adaptation with that scope. Do not present it as a completed feature. For a source-use uncertainty, offer private development or an original alternative while keeping the uncertainty visible.
