# Write the movie on the page
Inspect the outline, characters, scene map, and latest status. Use MASTER_PROMPT.md's full drafting, formatting, truthfulness, and character doctrine. Write actual screenplay scenes to screenplay/*.tex using the shared macros. Do not return an outline instead of dialogue/action or fill unwritten passages with “continue similarly.” Keep stable scene IDs in comments for later evidence. Update the assembly entry point if the structure changes.

Prefer filmable actions, performable dialogue, distinct voices and changing tactics. Give quiet characters consequential choices. Develop tonal variation and motifs whose meaning changes; cut decorative repetition. For true-story modes, distinguish documented events, composite characters, invented dialogue, and chronology changes in research/claims.json and creative_departures. Do not introduce proposed casting as an attachment.

Work in sequences sized to read and review. Keep continuity/status current and record exactly where to resume if the feature spans sessions. A requested short film is a short film; do not pad it to feature length. Write development/draft_report.md with actual files/sequences, limitations, unresolved research, and the complete/incomplete judgment. Mark the draft stage only when the requested draft is actually complete. Then recommend story-review, not immediate outreach.

Read DELIVERY.md. The assistant owns the default quality checks and repair work; do not reduce rigor because the writer is a beginner. At final handoff, record actual all-page inspection in visual_review.json and use scripts/delivery.py to prepare selected, current local files without private originals.
