# Make the consequential repairs
Read development/review.md and the actual cited scenes, then choose an ordered set of repairs that fits the writer's scope. Protect explicitly valued material. Fix cause/effect, choices, relationship structure, and ending before line polish. Re-read neighboring scenes and downstream consequences. Update story_bible, outline, scene_map, continuity and any source-claim mapping that changes.

Record each meaningful change in development/revision_log.md with problem, evidence, intervention, affected scenes, result, and remaining risks. Use bounded passes; stop cosmetic churn. Re-run the Bechdel and quality procedures against the revised files and make their receipts with the current draft fingerprint. A Bechdel report is required; passing is mandatory only if the writer chose that target. If upstream accepted documents changed, reopen the earliest changed stage and revalidate the existing artifacts in order; preserve the draft, do not mechanically rewrite it. Complete revise only after actual editorial review and mechanically current quality reports. Never set PASS/READY merely to advance the tracker.

Read DELIVERY.md. The assistant owns the default quality checks and repair work; do not reduce rigor because the writer is a beginner. At final handoff, record actual all-page inspection in visual_review.json and use scripts/delivery.py to prepare selected, current local files without private originals.
